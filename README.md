# Каэлмор

Коллекционная idle-RPG с пошаговыми боями 5 на 5 в стиле «Тёмный витраж».
Один код на TypeScript: игра запускается в браузере и собирается в приложения для Android и iOS через Capacitor.

> Статус: **все 8 этапов готовы.** Следующий шаг — онлайн: аккаунты, облачный сейв, друзья и чат.

## Что есть в игре

- **Бой 5 на 5** (PixiJS): шкала хода по скорости, ручной режим (навык → цель), авто-бой, ×1/×2/×3,
  анимации навыков, всплывающий урон и криты, статусы (яд, оглушение, снижение защиты/атаки,
  ускорение, замедление, провокация), щиты, волны, звёзды за бой. Бой детерминирован seed-ом.
- **Мир Каэлмор**: 5 фракций с бонусами за 3/4/5 героев, стихии Пламя > Терн > Камень > Прилив > Пламя
  и Свет ⇄ Тьма.
- **20 героев** 4 редкостей и 4 ролей, по 2–3 навыка с перезарядкой; уровни, звёзды (звёздная пыль
  или герои-копии), пробуждение на 6★; 3 сохранённых состава.
- **Кампания**: 3 главы по 10 этапов, босс в конце главы, 1–3 звезды.
- **Добыча лагеря** (idle) с лимитом 12 часов и экраном «С возвращением».
- **Призыв** с мягкой и жёсткой гарантией легендарного героя.
- **Снаряжение**: 6 слотов, сеты 2/4, улучшение до +15. **Подземелья**: 3 вида по 10 уровней.
- **Башня испытаний** (бесконечная), **арена** против ИИ с рейтингом и лигами,
  **ежедневные задания**, **награды за вход** (28 дней), **магазин** (задел под покупки).
- **Энергия** с восстановлением, **уведомления** на телефоне, **PWA** (офлайн и установка на экран).

## Быстрый старт

Нужен Node.js 20+ (проверено на 22).

```bash
npm install
npm run dev
```

Откройте адрес из консоли (по умолчанию http://localhost:5173). Флаг `--host` уже включён,
поэтому игру можно открыть и с телефона в той же Wi-Fi-сети по адресу `http://<IP-компьютера>:5173`.

Удобнее всего тестировать в DevTools браузера в режиме устройства (портретный телефон).

## Команды

| Команда            | Что делает                                                     |
| ------------------ | -------------------------------------------------------------- |
| `npm run dev`      | Запуск в браузере с горячей перезагрузкой                      |
| `npm run build`    | Проверка типов и веб-сборка в `dist/`                          |

| `npm run format`   | Prettier                                                       |

| `npm run android`  | Сборка, `cap sync android` и открытие проекта в Android Studio |
| `npm run ios`      | Сборка, `cap sync ios` и открытие проекта в Xcode              |

## Сборка под Android

1. Установите [Android Studio](https://developer.android.com/studio) (вместе с ней ставятся Android SDK и JDK 21).
2. `npm run android` — откроется проект `android/`.
3. В Android Studio выберите устройство или эмулятор и нажмите **Run**.

Сборка APK из командной строки (без Android Studio, если SDK уже установлен):

```bash
npm run cap:sync
cd android && ./gradlew assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Сборка под iOS

Нужен Mac с Xcode 16+.

1. `npm run ios` — откроется `ios/App/App.xcodeproj` (зависимости подключаются через Swift Package Manager).
2. В Xcode выберите команду разработчика в **Signing & Capabilities**.
3. Выберите симулятор или подключённый iPhone и нажмите **Run**.

## Тест по ссылке (PWA)

`npm run build` собирает `dist/` с манифестом и сервис-воркером. Залейте папку на любой статический хостинг
(GitHub Pages, Netlify, Vercel, Cloudflare Pages) — по ссылке игра откроется в браузере телефона,
её можно «Установить» на главный экран, и после первого запуска она работает офлайн.

## Перед публикацией

- Замените `appId` в `capacitor.config.ts` (сейчас `com.kaelmor.game`) на свой домен. После публикации его не поменять.
- Иконки и заставка уже сгенерированы (`public/icons`, ресурсы `android/` и `ios/`); исходник — `public/icons/icon.svg`.

## Структура

```
src/
  platform/      адаптеры платформы — единственное место, где есть Capacitor и API браузера
    types.ts     интерфейсы: Storage, Notifications, Haptics, Audio, Lifecycle
    web/         браузер: IndexedDB/localStorage, заглушка уведомлений, navigator.vibrate
    capacitor/   телефон: Preferences, LocalNotifications, Haptics, App
    shared/      общее для обеих платформ (звук на Web Audio)
  save/          сейв: схема с версией, миграции, нормализация, экспорт/импорт, бэкенды хранения
  core/          чистая логика без UI: RNG, стихии, формулы, характеристики, движок боя, ИИ
  content/       контент-конфиги: герои, навыки, враги, кампания, снаряжение, подземелья
  game/          правила поверх ядра: прокачка, энергия, кампания, idle, призыв, магазин,
                 снаряжение, подземелья, башня, арена, задания, вход
  render/pixi/   сцена боя на PixiJS (проигрывает лог событий движка)
  state/         запуск игры и глобальный стор (zustand)
  i18n/          тексты интерфейса (ru.json; en и uk добавляются рядом)
  ui/            React: оболочка, компоненты, экраны (грузятся лениво)
  assets/art/    арт: SVG-заготовки бойцов и реестр
tests/           unit-тесты Vitest
android/, ios/   нативные проекты Capacitor
```

### Правила архитектуры

- **Игровая логика не знает, где запущена.** Всё платформенное спрятано за интерфейсами в `src/platform/types.ts`.
  `createPlatform()` выбирает реализацию: в браузере web-адаптеры, на телефоне Capacitor-адаптеры.
  Нативные модули грузятся динамически и не попадают в веб-бандл.
- **Сохранения версионируются.** В сейве есть поле `version`. Чтобы поменять формат: поднимите `SAVE_VERSION`
  в `src/save/schema.ts`, добавьте шаг в `src/save/migrations.ts` и тест к нему. Битые поля заменяются значениями
  по умолчанию, а если основной сейв повреждён целиком, игра поднимает резервную копию.
- **Облачный сейв** добавляется новой реализацией интерфейса `SaveBackend` (`src/save/backends/`).
  `SaveManager` с ним уже работает: нужно только решить конфликт по `updatedAt`.
- **Тексты только через i18n**: `t('camp.level', { level })`. Новый язык — это файл `en.json` / `uk.json`
  с той же структурой.

### Как заменить арт

Каждый боец — файл `src/assets/art/units/<ключ>.svg` (холст 120×135, ноги в точке 60,130).
Чтобы поставить готовый спрайт, положите рядом `<ключ>.png` или `<ключ>.webp` того же формата:
реестр (`src/assets/art/index.ts`) автоматически предпочтёт растровый файл. Код менять не нужно.
Высоту спрайта для полосок HP задаёт `src/assets/art/meta.ts`.

## Как добавлять контент

- **Герой**: запись в `src/content/heroes.ts` (фракция, стихия, редкость, роль, навыки) и спрайт `src/assets/art/units/<art>.svg|png`.
- **Навык**: запись в `src/content/skills.ts` — набор эффектов (урон, лечение, щит, статус, шкала хода, очищение).
- **Враг / этап**: `src/content/enemies.ts`, `src/content/campaign.ts`.
- **Сет снаряжения, подземелье**: `src/content/gear.ts`, `src/content/dungeons.ts`.
- Проверка ссылок контента — тест `validateContent()`.
